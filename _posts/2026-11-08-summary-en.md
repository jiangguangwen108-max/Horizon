### [Goldman Sachs reportedly pulls Claude Code from bankers and traders](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers) ⭐️ 7.0/10

Goldman Sachs is reportedly pulling Claude Code from its bankers and traders, according to a report for which only the headline and reader comments were supplied. The available material does not give the number of affected users, a timeline, or Goldman&\#x27;s stated reason, so the scope and rationale remain unconfirmed. The move concerns Anthropic&\#x27;s coding agent, which can operate on files and systems from a user&\#x27;s workstation, making its access controls and auditability central to any enterprise deployment.

hackernews · TheWiggles · Nov 8, 18:16 · [Discussion](https://news.ycombinator.com/item?id=50415628)

**「Background」** The reported restriction follows an earlier one in April, when Goldman barred its Hong Kong bankers from using Claude, according to the same report. As recently as July, CIO Marco Argenti had publicly praised &quot;vibe coding&quot; by non-technical staff, while the new move limits coding tools such as Claude Code and GitHub Copilot to engineers.

**「Impact」** For affected bankers and traders, the concrete consequence is losing an agent that runs alongside sensitive client, trade, and proprietary data; commenters argue that semi-unattended access from primary workstations conflicts with controls on email, internet, and internal networks. Any replacement would still need to satisfy entitlement, audit, and data-access requirements, not merely match Claude Code&\#x27;s capabilities.

**「Community Discussion」** Commenters split between a security explanation—one called coding agents on finance professionals&\#x27; primary machines a &quot;lethal trifecta&quot; of sensitive data, email, and network access—and an operational one, with another saying their own organization cut Claude access over chronic billing overages and that Gemini&\#x27;s flat billing and throttling are displacing it. Others raised compliance and audit burdens, the timing relative to Anthropic&\#x27;s IPO, and speculation about an operational loss, none of which the supplied material establishes.
